AROMATIC POS Android APK Ready Project

1. Install Node.js and Android Studio on a PC.
2. Open this folder in Terminal.
3. Run: npm install
4. Run: npx cap add android
5. Run: npx cap sync android
6. Run: npx cap open android
7. In Android Studio use Build > Build APK(s).

This folder is Android-ready but the APK binary is not included because the current build environment does not have Android Studio/Gradle SDK installed.
